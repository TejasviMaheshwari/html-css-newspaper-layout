# HTML & CSS Newspaper Layout

## About the Project

This project is a simple newspaper-style webpage created using HTML and CSS. The design is inspired by *The Times of India* and demonstrates basic webpage structure, styling, and multi-column text formatting.

## Features

* Newspaper-style heading and layout
* Scrolling headline using the HTML `<marquee>` element
* Three-column text layout using CSS
* Styled headings and paragraphs
* Basic CSS spacing, borders, and background colors

## Technologies Used

* HTML5
* CSS3

## Project Structure

```text
html-css-newspaper-layout/

```

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `Assignment2.html` in any modern web browser.

No additional software or installation is required.

## Learning Outcomes

* Understanding the basic structure of an HTML document
* Applying CSS to style webpage elements
* Creating multi-column text layouts
* Using headings, paragraphs, and scrolling text
* Practicing HTML and CSS through a practical assignment
